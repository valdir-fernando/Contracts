# Entrega de 19/10/2026

Inclui normalização de nomes de usuários/fornecedores em maiúsculas, proteção do perfil na própria conta, testes do armazenamento de senhas por hash, PDF privado de Fornecimento com produtos/dotações e cabeçalho ajustado, seleção editável de fichas e importação rastreável dos produtos legados.

As três falhas citadas nos relatórios anteriores foram investigadas: a normalização em maiúsculas já estava implementada e testada nos fluxos de cadastro, mas três expectativas antigas ainda exigiam nomes com outra capitalização. Foram atualizadas somente essas expectativas em `AuditCorrectionsTest`, `CatalogDelegationTest` e `SupplierAssistanceTest`; as verificações de autorização, isolamento, escopos e persistência foram mantidas. A repetição desses grupos passou com 36 testes e 267 asserções.

Validação antes do push:

- `docker compose exec -T app composer check`: Pint passou em 299 arquivos; PHPUnit concluiu 603 testes e 5.556 asserções, sem falhas, com 1 teste de concorrência MySQL ignorado por falta de schema descartável configurado. Este resultado substitui as limitações de capitalização relatadas nas validações anteriores.
- `npm.cmd test`: 90 testes JavaScript passaram.
- `npm.cmd run build`: build Vite concluído.
- `git diff --check` e revisão das alterações preparadas para commit: sem erros.

Os testes PHP usam SQLite em memória e storage/cache temporários. Backups, dump do banco de modelo, dados do banco local, `.env`, fotos pessoais e prévias temporárias não integram os commits. Os modelos Word e as referências de produtos/dotação necessários ao desenvolvimento acompanham o código. As importações executadas localmente estão documentadas; o push não transporta o conteúdo do banco.

O acesso local foi conferido em `http://localhost:8000`. Após o encerramento do servidor de desenvolvimento Vite, a referência temporária `public/hot` foi removida e a aplicação voltou a carregar os arquivos compilados, ambos respondendo HTTP 200. Esse arquivo é ignorado pelo Git e não integra a entrega.
